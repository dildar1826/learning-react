# Context API and useContext Project

This project is created for **learning and practice purposes only** to understand the Context API and basic state management in React.

## 🚀 What I've Used So Far
As I build and explore this project, I have implemented and experimented with the following core concepts:
* `createContext()` — To create a centralized context object for sharing data globally.
* `Context.Provider` — To wrap parent components and supply state down the component tree.
* `useContext()` — To easily consume and access context values inside child components without hassle.
* **Prop Drilling** — Explored passing props manually through multiple intermediate components to truly understand the pain points that Context API solves.
* `useState` — To manage local component state and update the shared context values dynamically.
* All other React basics (functional components, component composition, props, and event handling)...
