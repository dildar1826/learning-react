# React Mini Projects

This repo is where I'm learning React, one small project at a time.

My approach: watch a tutorial or read docs once, then close it and rebuild
the project from memory. Whatever I forget or get stuck on, I look up
directly instead of re-watching passively — trying to build actual
understanding instead of just following along.

Some of this code is rough. Some of it is genuinely bad. That's expected —
it's a learning log, not a portfolio. If you're checking my progress,
look at the folder numbers — they're roughly chronological.
